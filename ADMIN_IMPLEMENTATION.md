# Админка RustPG и разделение книги/посоха

План: посох только переключает/выбирает записанные заклинания; книга меняет набор. Удалить переход в книгу из меню посоха.

/rpgadmin: семь разделов — быстрые действия, предметы, сущности, игроки, RustPG, каталог команд, консоль. Каталоги берутся из установленной игры. Поиск, страницы, количество, выбранный получатель, выдача/спавн в один клик. Серверные команды идут через ConsoleSystem с реальным соединением администратора; клиентские отправляются только на его клиент и подчиняются ограничениям Rust. CUI не заменяет локальный F1 и не может обходить AllowRunFromServer.

Проверка прав на открытие и каждое действие, закрытие при отключении/смерти/потере прав. Нет исполнения из поля ввода без кнопки «Выполнить». Консоль хранит ограниченную историю и постраничный вывод. Пароли не попадают в журнал/историю.

Статус: выполняется.
